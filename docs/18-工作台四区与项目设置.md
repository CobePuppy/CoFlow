# 工作台四区与项目设置升级

工作台默认展示“我的项目 / 我的待办 / 竞赛与截止提醒 / 最近成果”，按当前团队汇集本人可访问项目，不再复用当前项目的任务表。待办按截止时间排列，点击打开需求；项目进入独立项目页，最近成果进入对应项目文档。工作台每15秒同步。企业版第三块为截止提醒。

项目设置入口位于工作台项目卡片、项目页标题栏及首页项目管理卡片。团队管理员可修改名称与介绍、管理成员、归档及恢复。空项目可输入准确名称后永久删除；非空项目返回明确提示，使用归档保留业务记录。归档项目需先恢复才可删除空项目。删除保留审计事件，没有批量删除业务材料。

需求创建时可选择同团队本人有权限的未归档项目，切换时清空负责人供重新分配。未提交普通草稿可调整项目，重新校验目标成员、项目权限、版本及归档状态，按目标项目生成新编号并记录审计。已提交历史、缺陷、附件、文档、通知、子缺陷、成果验证或项目分身引用存在时拒绝转移，防止跨项目引用失效。

新增接口：GET /workspaces/:id/overview；DELETE /projects/:id（confirmName确认）。已有项目PATCH支持description；需求PATCH支持受保护的projectId调整。没有新增数据库迁移。

验证：40项单元测试、2项数据库集成测试通过；工作台及项目设置专项、正常交付、缺陷重测、需求表单及手机导航共4项浏览器场景通过。生产构建及类型检查通过。专项追加验证编辑草稿调整所属项目后再次执行。

最终专项追加回归通过：创建需求时选择项目B，编辑该草稿切换至项目A并重新选择五项责任人，保存后API确认归属已迁移；桌面截图及390px手机截图已更新，未出现横向溢出。最终格式检查通过。截图位于 artifacts/browser/work-dashboard.png、work-dashboard-mobile.png。本轮为本地实现与验证，未更新服务器发布入口。
