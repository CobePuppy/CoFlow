## 集成场景覆盖

综合场景运行了多角色账号及真实事务，验证：

- 正常交付、测试失败退回后新轮次，阻断缺陷通过完整流程关闭前不得放行父任务。
- 只有一个评估槽位通过时禁止开发；方案退回后两个槽位重评；并发双评估一方冲突、刷新后重试正确汇合。
- 同账号双评估及方案提交人审批在单元测试拒绝；非指定人操作在 API 拒绝。
- 幂等重放无重复提交、同键不同内容冲突、过期任务/文档版本返回 409。
- 需求变更产生新需求版本，旧评估失效；历史方案和需求保留。
- 阻塞期间禁止前进，解除继续；单元测试验证阶段总/净耗时差。
- 跨团队任务、文档、附件、列表及统计 404；同团队非项目成员 403；未认证及过期会话 401。
- 评论提及成员范围检查、通知生成、真实文本附件鉴权下载、伪造 PNG 拒绝。
- 邀请预览、受邀注册、重复领取拒绝、团队最后一位管理员保护。
- 责任转交后旧研发无权提交、新研发产生待办；有未结束责任时不能移除成员。
- 注入审计写入错误后任务、审计、通知均不变；注入只在测试库进行并于 finally 清理。
- 数据库直接覆盖需求/文档历史及向归档项目写入被约束拒绝。
- 种子重复执行不增加重复任务。
