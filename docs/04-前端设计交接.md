## 视觉方向

主界面采用 CoBuild 蓝色作为主操作强调，110lab 工作区的白色表面与灰蓝画布作为信息承载。登录页可用轻微玻璃或渐变；密集列表和详情区保持实色表面，确保中文正文和表格可读。

建议起点（需在正式设计中验证对比度）：主色 `#1449FF`，深色正文 `#07122C`，业务正文 `#1A1D23`，页面背景 `#F3F5F8`，白色卡片 `#FFFFFF`，分隔线 `#E1E6EE`。状态使用带文字的蓝/紫/青/绿/橙标签，不能仅靠颜色。以 4/8px 间距体系、10–14px 业务卡片圆角和系统中文字体保持一致。

保留 汇流 自己的业务层级：左侧团队及项目导航；主区任务列表/阶段看板；任务详情的流程条、处理人和允许操作。登录页与品牌说明可以有更大留白，列表应优先信息密度。

请为 汇流 设计一套简体中文桌面端团队协作平台 UI。

它面向产品、研发、测试/运维团队，业务流程为：需求草稿→待出方案→方案评估中→待开发→开发中→待测试→测试中→待验收→已关闭；已取消单列。方案评估需要产品和测试两个独立槽位。

设计参考为用户提供的 pythc/cobuild-homepage 与 pythc/110lab-website。视觉上结合前者的清晰蓝白品牌与协作感、后者工作区的实用白色画布及克制玻璃质感。不要用大幅营销首屏占据业务工作台。创建 汇流 自己的组件与标识。

请先制作三个 1440px 宽的主页面及组件规范：
1. 我的工作台：左侧团队/项目导航，顶部面包屑与通知；待我处理、我负责、阻塞和逾期任务；任务列表有标题、阶段、当前处理人、优先级、截止时间与阻塞标记；支持状态/负责人/优先级/关键词筛选与分页，提供列表/看板切换。

3. 任务详情：清楚显示流程条、当前处理人、版本号与允许动作；按“需求、方案与评估、开发、测试与验收、动态”分区；展示两个独立评估槽位、方案/需求版本、测试轮次及历史。

补充登录/邀请注册、项目文档及版本冲突、成员角色管理、通知页的布局规范。为新建需求、方案提交、退回理由、开发交接、测试结论、逐项验收和需求变更准备统一表单组件。

技术落地目标：React + TypeScript + Vite + Ant Design；输出可编辑画板、颜色/字号/间距/圆角变量、组件状态及桌面/平板/手机适配规则。业务 API 与数据库已经存在，页面数据最终由真实 API 提供，不用静态演示数据冒充完成。
