# 团队边界与多团队身份（v2.3.0）

## 团队管理与项目管理

团队成员页只展示当前团队的成员、邮箱、团队身份和邀请/团队码。取消此页的项目选择器；团队成员管理弹窗不再请求或展示项目成员、项目角色和项目归档。

项目成员、产品/研发/测试/运维角色以及归档入口保留在项目管理上下文，从项目设置进入。竞赛中的参赛成员入口也使用独立项目成员弹窗，不再混入团队邀请或团队身份编辑。

## 多团队使用

门户与需求工作区的侧栏均新增“加入或创建团队”。已有账号可通过团队码加入另一团队、创建新团队、查看自己的各团队身份及切换团队；不需要注册另一账号。加入新团队不会自动加入其项目。

- 团队列表接口返回当前用户在每个团队的 role。
- POST /api/v1/workspaces/join 校验12位团队码，为已登录用户创建 MEMBER 成员关系。
- 复用 WorkspaceMember 的 workspaceId/userId 联合主键，不增加数据库迁移。
- 重复加入使用 upsert 且 update 为空，既有管理员身份不会被改成普通成员。
- 创建新团队的用户只获得新团队 ADMIN 身份，不影响其他团队。
- 团队角色修改继续校验目标团队管理员权限，并保留至少一位管理员。
- 切换团队时清除原项目及任务上下文，关闭旧团队管理窗口；页面按新团队成员关系重新判断权限。
- 创建与加入团队均记录审计事件，不自动发送邮件或其他外部消息。
