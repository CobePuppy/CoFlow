# 企业版品牌与蓝色主题（v2.3.2）

直接使用用户提供的企业版蓝色品牌图，保留其图形、文字、渐变与企业版标识。通过共享 BrandMark 按版本路径选择企业或学生资产；原图分别存放于 apps/web/public/brand，生产构建自动复制到 dist/brand。

颜色层级覆盖登录、白色侧栏、门户欢迎区、应用图标、个人菜单、统计卡片、表格、需求编辑与阶段流转。渐变仅用于欢迎区及登录背景；常规卡片以白底和细边框呈现。警告、错误与成功保留语义色，不将风险状态变成品牌蓝。学生版继续使用独立青绿主题。

验证：类型检查、格式检查与前端生产构建通过；已确认企业品牌图包含于构建目录。三个浏览器场景通过，覆盖双版本主题、头像菜单与设置退出、学生版竞赛文书与版间切换。截图可见 artifacts/browser/theme-enterprise.png 和 account-menu-enterprise.png。

产品/前端为 2.3.2，后端保持 2.3.0。状态 validated，本轮尚未部署；2.3.1 的历史发布记录保留。
