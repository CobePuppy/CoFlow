## 第一轮：澄清跟进与通知定位

新问题可指定项目内跟进人和北京时间截止日，问题作者、跟进人或需求负责人可说明原因后转交、调整日期、解决或重新打开。变化追加记录，原问题不改写。旧问题没有登记过的负责人和版本不会补造。

团队澄清中心支持本人跟进、本人提出、全部可见问题，以及解决状态、逾期和编号搜索；只聚合有访问权的未归档项目，排除回收站。需求已关闭但尚未解决的问题仍可追踪。正式需求换版提示人工核对，不自动改变审批和问题状态。

通知排除操作者本人，并检查当前项目与团队成员；打开后直达动态记录的具体讨论，支持刷新和企业/学生版本切换保留定位。

验证：94 项单元、10 项隔离数据库集成、类型、格式及生产构建；两版跟进与通知场景、3 项原讨论工作副本场景共 5 项浏览器验证通过，含 390px 布局。集成覆盖并发冲突、非法指派、可见范围和审计失败回滚。

## 第二轮：文件内容版本与引用方式

个人空间和团队空间均可更新文件内容，历史内容不可改写。恢复历史会追加新版本，保留后续历史；文件最多 1000 个内容版本，历史列表分页。维护沿用上传者或团队管理员权限，个人空间保持所有者隔离。

需求引用可固定历史内容或跟随最新版。个人文件固定授权不能由项目维护者自行扩展到未来版本；只有文件所有者可调整其引用方式。文件被删除、授权被撤销后，历史引用和当前引用均停止下载。

备份、恢复验证及孤儿清理的有效文件清单包含全部内容版本，恢复复用的存储键去重保留；历史查询失败即停止，不能忽略历史文件继续清理。

验证：95 项单元、11 项隔离数据库集成、类型、格式及生产构建通过；两版新增版本/恢复/引用模式与 3 项原引用回归共 5 项浏览器场景通过。真实备份 817 个文件、612 条内容版本，恢复到新建独立数据库和目录后，任务数、文件元数据和 SHA-256 一致；只读清理预览确认历史文件不进入删除候选，未执行清理删除。

## 第三轮：GitHub 诊断与导航保护

诊断分别说明服务器客户端标识、加密参数、安装入口、个人连接记录和真实账号验证结果。只返回配置有效性，不返回或修改配置值。安装入口缺失与不能登录分别提示，参数齐备不作为具体仓库读取成功的证明。

个人账号验证调用测试或实际运行环境的 GitHub 客户端，检查当前账号及可见安装数量。测试使用隔离 GitHub 服务；本次没有配置、验证真实 GitHub App，没有更换既有加密密钥。

导航保护覆盖页面、项目、团队、详情关闭、设置返回及浏览器前进后退。同一详情内切换页签保留输入；成功保存需求后先清理编辑状态再导航，避免误报未保存。已成功保存在浏览器的工作副本仍沿用原恢复规则。

验证：97 项单元、11 项隔离数据库集成、类型、格式及生产构建通过。新增 3 项导航/诊断、原 4 项工作副本、原 3 项讨论副本及 1 项 GitHub 浏览器场景经分批复验通过，两版产物版本信息已核对。

## 第四轮：首页摘要与讨论增量读取

保留原 `/workspaces/:id/overview`、`/tasks/:id` 和评论接口默认响应；新首页使用摘要，需求详情显式选择不携带讨论正文，再按需读取讨论。增量位置采用追加数组偏移；回复、状态和指派都作为新记录返回，服务端每次重新检查成员权限。偏移超过历史长度时返回完整重置；客户端拒绝位置不一致或不完整的增量，避免静默丢记录。

查询只返回首页卡片需要的需求字段，当前处理人规则与需求列表共用，审批已完成本轮的人员不再计为待办。首页不重复请求完整个人待办或项目统计。讨论归并、搜索回复和渲染使用一次分组；澄清中心按任务统一展开事件，连接最新状态和指派。

隔离数据库夹具对照：完整首页 1,988,732 字节，摘要 3,188 字节；首次讨论 153,877 字节，无变化增量 91 字节，新增一条回复增量 363 字节。1200 个问题的实际查询计划只有 1 个事件展开节点，执行 13 次；数字来自测试夹具，不作为生产延迟或任意数据规模的承诺。原接口待办集合、项目数量、状态、截止日、阻塞原因、审批轮次和成员权限逐项对照。

最终验证：99 项单元、12 项隔离 PostgreSQL 集成、类型、全量格式及前后端生产构建通过；17 项不同浏览器场景经分批复验通过，含双版本增量读取、旧链接定位、刷新保留输入、原讨论流程、通知定位、工作副本及导航保护。两版 390px 截图和 3.14.1 / 2.21.1 产物已核对，详情见根目录 CHANGELOG.md 的 3.14.1 条目。首次加载讨论仍读取全部历史；本轮没有实现历史分页或虚拟列表。
