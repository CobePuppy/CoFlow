# 文档与需求双向关联（2026-10-17）

本轮新增一条完整的使用路径：需求详情 → 关联文档 → 文档查看/编辑 → 关联需求。复用现有文档的 taskIds，无需数据库迁移。

## 使用方式

1. 在知识库新建或编辑文档，在“关联任务”中选择同一项目的需求并提交。
2. 打开需求详情，切换“关联文档”，按标题进入对应文档。
3. 文档中“关联需求”展示需求编号、标题和当前状态，可直接跳转。
4. “复制文档链接”生成含团队、项目、文档标识的地址。刷新地址仍会打开该文档，接收者需要拥有项目访问权限。
5. 修改文档关联任务并提交后，需求侧关联列表随查询更新。解除关联后，需求不再列出该文档。

## 新增接口

| 接口 | 返回内容 | 访问规则 |
| --- | --- | --- |
| GET /api/v1/tasks/:id/documents | 文档 id、标题、版本、更新时间、项目与团队标识 | 先检查需求所属项目权限，再按项目和 taskIds 查询；不返回正文或版本历史 |
| GET /api/v1/documents/:id/tasks | 需求 id、编号、标题、状态 | 先检查文档所属项目权限，只返回同一项目内的关联任务 |

未登录沿用会话校验返回 401；跨团队或无项目访问权限沿用 404。归档项目仍可读取链接和关联内容，文档提交继续受现有归档写入保护。未新增共享权限或公开文档能力。

## 前端变化

- 知识库项目选择保存在 URL，直达链接可以选中指定项目。
- 切换团队或项目时移除旧文档标识，文档编辑器按项目隔离。
- 直达不存在、无权限或与当前项目不符的文档会显示错误及重试入口。
- 需求侧提供关联为空、加载中、加载失败和重试状态。
- 当前修改中的文档不会仅因同一文档查询刷新而重置输入；切换文档时应打开对应表单。
