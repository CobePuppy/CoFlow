# 个人与团队文件空间

入口：知识库 → 个人文件空间 / 团队文件空间 / 项目资料。企业版和学生版共用同一套账号权限。

- 个人文件空间只属于当前账号，不需要项目或团队。团队管理员也不能读取他人的个人文件；切换团队不改变个人文件归属。
- 团队文件空间属于当前团队，无需创建项目即可存放开发规范、公共模板和入职材料。当前团队成员可以上传和下载，上传者或团队管理员可以重命名、删除和恢复。成员退出后立即失去后续访问权，之前上传的团队资料继续保留在团队。
- 项目资料保留原有项目文档、独立项目文件与需求附件，继续检查项目成员及归档状态。旧的带project参数的知识库链接默认打开项目资料；从知识库导航进入默认打开个人空间。

支持按文件名搜索、每页20条分页、下载、保留扩展名的重命名及软删除恢复。重命名冲突会保留输入并载入最新版本，需核对后再次保存。团队管理员可查看全部已删除文件，普通成员仅查看自己上传的已删除文件。

上传复用20MB限制、文件签名和UTF-8校验，支持PNG/JPEG/PDF/TXT/Markdown/DOCX/XLSX/ZIP。文件名相同也不会覆盖原文件；文件正文不自动发送给AI。下载需要有效登录和当前空间权限；被删除的文件停止提供下载。

## 升级与维护

新增迁移：20261020020000_file_spaces；新增SpaceFile、SpaceFileEvent表。原Attachment和Document表不变，不移动已有项目文件。

升级时生成Prisma客户端、应用迁移后再启用新版API与前端。请使用项目db:migrate流程，不要使用db push覆盖手写约束。当前仅隔离coflow_test库应用新迁移，开发与生产数据库未变动。

独立文件使用同一STORAGE_DIR，存储键带sf-前缀。备份、恢复校验和孤儿清理会同时读取项目附件与独立文件，包括软删除文件，保留恢复能力。只有超过24小时且无任何元数据引用的随机文件才是孤儿清理候选；默认清理仍是只读预览。恢复旧备份时允许不存在独立文件表。

API：GET/POST /me/files；GET/POST /workspaces/:workspaceId/files；GET/PATCH/DELETE /space-files/:id；POST /space-files/:id/restore；GET /space-files/:id/download。修改必须提供expectedVersion，空间、所有者及原始内容不可通过重命名改变。

本轮不提供个人/团队/项目之间的移动、公开分享链接、文件正文在线编辑或永久删除界面。
