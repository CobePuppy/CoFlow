# QQ设置整合与操作按钮美化（2026-10-17）

## 美化计划与落地

返回工作台改为带左箭头的浅底圆角导航按钮；查看/编辑、文件下载、关联需求改为紧凑次级操作。主操作保留品牌色，删除保留红色。正文引用链接不一并改成按钮。统一圆角、边框、悬停、键盘焦点和禁用态；学生版沿用绿色，企业版沿用蓝色，窄屏点击区域至少40px。

## QQ整合

个人设置新增QQ与团队集成，支持团队切换、个人绑定/解绑、管理员配置专用令牌、服务端启停、网站链接、私信提醒开关与北京时间提醒时刻。独立团队表单与个人设置表单分开，避免嵌套表单。URL保存设置页签与团队，刷新后保持。

服务端只保存机器人专用令牌SHA-256摘要及末4位。新令牌仅在本次输入内存中存在，可生成、复制，保存后不回显。不同于个人DeepSeek API Key，不能互用。

插件1.1.0新增workspaceId和syncPolicy。机器人请求通过X-CoFlow-Workspace指定团队；省略时兼容原QQ_BOT_WORKSPACE_ID环境变量。网页配置优先于环境变量，停用不会退回旧环境变量配置。新插件开启同步后最多30秒同步一次提醒时刻；本地pushEnabled也须开启。服务端关闭提醒后接收人接口返回空列表，手动查询仍可用。状态仅代表配置完成，不代表真实QQ在线。

## 发现并修复的逻辑项

- 原来学生版成员页没有QQ入口，现两个版本均可从设置访问。
- 原来未配置/停用时不能查看或解除旧绑定，现仍允许查看和解绑，只禁止生成新绑定码与机器人访问。
- 生成绑定码后自动轮询兑换结果，显示到期状态，切团队不带旧绑定码。
- 任务链接补全项目参数并清理旧查询与锚点，优先使用收件人的版本偏好。
- 团队配置有管理员权限、版本冲突、审计和令牌摘要保护；同步团队策略需要更新插件。
- 安装器检查网页已保存凭据，避免重新安装用旧环境变量覆盖插件令牌；不匹配时停止并给出同步指引。
- 修正团队切换遗留项目上下文、非法设置页签回退、刷新设置后错误提示不清除。

## 升级与边界

新增迁移202610170005_qq_settings并重新生成Prisma客户端。机器人部署端需要更新integrations/qq-agent/coflow下的插件文件并重启插件。API和设置界面在本机生效，不会自动修改外部QQ-Agent安装目录，也未发送真实QQ消息。跨机器机器人API连接须HTTPS。密钥不在日志或GET响应中返回。

## 验证结果

40项单元测试、2项数据库集成通过，覆盖策略同步、团队并发隔离、令牌轮换、权限、停用解绑和旧环境变量兼容。6项相关浏览器场景分批通过：个人AI设置/FirstStep、首页、知识库、ProofLoop、QQ设置及学生版。类型检查、格式检查与生产构建通过。桌面和390px截图已复查，页面无横向溢出；按钮图标为装饰，不改变读屏操作名称。没有发送真实QQ消息或修改外部机器人部署。
