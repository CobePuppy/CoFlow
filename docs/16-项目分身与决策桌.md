# 项目分身与决策桌

## 前端风格与交互复查

页面采用浅鼠尾草绿背景、青绿/淡紫路线标识与分叉示意图。预算和实际投入使用独立数字面板，试验进度、结论、成果分层展示。移除本页无关的通用需求统计，移动端路线纵向排列、比较表内部横向滚动。默认打开最近更新的探索，支持按名称搜索切换；重复路线名称使用独立表格行标识。已决策路线的超预算提示只陈述历史偏差，不再建议修改。上下文时间明确为北京时间。

复查覆盖创建、路线编辑、预算提示、键盘切换探索、跨路线成果合并及只读历史。桌面和390px窄屏截图已检查；类型检查、格式检查和生产构建通过。

第二轮优化：创建表单双列对照路线，编辑表单区分试验与成果；弹窗正文独立滚动，底部操作保持可见。决策前展示每条路线的缺失条件，默认选择已具备决策条件的路线。完成试验的实际结果在前端就地校验；参考资料按名称搜索并限制选择数量。新增桌面创建弹窗、手机编辑弹窗截图，并验证页面无未捕获运行错误。

## 使用流程反思与改进

原版重在展示信息，仍有“刷新丢失选择、缺少下一步、合并后需要手动找文档”的断点。本轮将当前探索写入 URL 的 fork 参数；链接不属于当前项目时明确提示，不自动显示其他记录。新增下一步面板，按路线列出尚缺的试验、投入或结论，直接进入编辑。已选项目的宣传区缩短，给实际工作留出更多空间。

创建、编辑和决策表单发生修改后，关闭需确认放弃；选择继续编辑保留原输入。保存成功/失败提供即时反馈。决策后的每份成果与决策记录均有直达链接。新增浏览器断言验证：存在更新的其他探索时刷新仍保留当前项、取消放弃后输入保留、点击决策记录进入对应文档编辑器。

入口：学生版或企业版 → 需求协作 → 选择项目 → 项目分身。

围绕一个决策问题建立两条路线，填写共同目标、比较口径、各自假设与最小试做计划。每条路线单独维护人时/人民币预算、北京时间截止日期、试验任务、负责人、实际结果及成果内容。实际投入留空表示未记录，0 表示据实记录为零；超预算及逾期会提示组织决策。

创建时可选择项目文档与需求作为参考。文档保存正文和版本快照；需求保存编号、标题、状态和版本快照，项目描述也被冻结。参考资料后续修改不会覆盖快照。资料选择器显示前100项；试验任务独立存在于探索路线中，不推进原需求的交付状态。

编辑路线时可增加试验和成果。完成试验必须填写结果；负责人必须属于当前项目。成果可记录说明、代码仓库链接及运行结果来源。当前不运行代码、不自动下载外部资料，也不会将填写的结果自动认证为真实。

决策桌并排比较预算、实际投入、完成试验和结论。选定路线需要全部试验完成、至少一项试验、实际工时/费用和结论。填写选择理由、放弃其他路线的原因及重启条件，并勾选需要保留的成果，允许跨路线选择。

确认后，事务内创建一份决策记录及所选成果文档；原文档保留，两个路线冻结为只读历史。合并对象是成果内容与决策记录，不进行 Git 代码合并、不自动重排原项目任务。未选路线可以尚未完成，其未记录项在决策文档中明确展示。

权限沿用团队及项目成员，归档项目只读；所有写入重新检查项目权限，使用项目锁串行化和 expectedVersion 防止覆盖。决策重复提交返回409，不能重复生成文档。创建及修改写入审计；数据库复合外键和归档触发器提供额外保护。
