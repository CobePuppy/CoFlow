# 需求工作副本与字段填入

本轮产品与前端版本为3.6.0，后端仍为2.14.0。

## 工作副本

创建/编辑需求、草稿正文及提交方案时，输入会保存在当前浏览器的本地存储。它不是正式需求或服务端方案草稿，不会通知接手人，也不会同步到其他设备。关闭窗口或刷新后，再进入相同账号、团队、项目和编辑入口，可以主动恢复、查看或舍弃副本。需求编辑已有输入时锁定所属项目，避免误换归属；要切换项目，请先保存或关闭表单。

不同账号、团队、项目、任务及编辑入口使用独立键。已存在的待恢复副本不会被新输入静默覆盖；请先选择恢复或舍弃。检测到其他页面更新副本时停止覆盖，提供核对入口。工作副本超过30天不再提供恢复，单份上限约100万字符；浏览器清理站点数据会移除副本。存储不可用或空间不足时提示复制输入，当前编辑内容仍保留。

正式内容版本已变化时，旧副本仅供查看复制，禁止直接恢复。正式保存或提交成功后清除本页写入的副本；失败保留。方案仍可显式“保存方案草稿”到服务端，沿用现有权限、版本及审计规则。

## 提交定位

创建并提交时检查需求正文、验收标准、成员及评估独立性。缺项列出可点击入口，展开补充信息并滚动、聚焦对应字段；标题为空仍使用表单校验。仅保存草稿仍只要求标题，服务端校验保持不变。

## 模板字段

应用模板先展示当前值与模板值，可勾选标题、背景、目标、描述、验收标准和优先级。确认后只替换勾选字段，负责人和截止日期保留。未勾选任何字段不能填入；取消预览保留输入。

## 发布

无数据库迁移。此版本只改前端，不改变API。工作副本属于当前浏览器的站点数据，切换设备或站点地址需要手动复制。构建与本地验证不代表已部署。
