# 参考Makit的需求页设计迭代

参考：用户授权只读查看Makit需求详情及其关联来源。已观察到正文主区、右侧“下一步”与准备状态、基本属性、正文编辑入口和独立验收页签。本轮只参考布局和交互，不修改参考站点数据，不复制其内部需求内容。

落实到CoFlow：
- 默认先展示详细信息，AI评审和关联材料放到后续页签，增加独立“验收项”。
- 正文顶部新增明确“编辑内容”，与点击段落编辑、文件导入共存。整体编辑仍先预览再保存，保留版本冲突与权限约束。
- 右侧基本信息上方新增“下一步”卡片，显示目标阶段、当前处理人和主要流转操作；辅助操作保留在次要操作栏。
- 草稿准备状态拆为正文缺项、分工缺项和阻塞，附补全正文及调整成员入口。提交确认框复核准备状态；未齐备时不能确认提交，服务端仍保留独立最终校验。
- 手机端优先显示下一步，其后正文和属性仍可访问。

没有改变CoFlow原有后端阶段、角色或审批规则，没有增加数据库迁移。
