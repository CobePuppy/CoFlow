# 需求属性点击与草稿分工修复

属性面板的优先级、负责人下拉菜单现挂载在属性浮层内部，避免外层弹窗将菜单选项操作视为外部点击。浮层关闭回调仅关闭自身对应字段，防止旧浮层的关闭事件清掉新打开的属性。保存成功显示明确反馈，失败保留当前选择并展示错误。

同时修复草稿分工的校验时机：创建草稿时可以先由同一人暂时兼任多个责任，但原TRANSFER立即校验正式评估人的独立性，可能阻止逐项补全分工。现在DRAFT的逐项转交只校验项目成员身份；正式提交以及非草稿阶段仍严格校验两名评估人不同、研发不得审批自己的方案。越权与归档限制保持有效。

验证：45项单元测试通过，新增同人兼任草稿的逐步调整、非项目成员拒绝及提交独立性校验。浏览器专项验证P0-P3反复选择及保存、取消保持旧值、四项负责人调整、计划截止及390px窄屏操作通过。没有数据库迁移，尚未部署服务器。
