# 常用视图与通知中心（v2.10.0）

## 常用视图

在项目需求或团队待办列表上方，点击“保存当前视图”，为当前筛选命名。视图保存到服务器，仅本人可见，并按团队隔离；同一账号其他浏览器或设备登录后也可使用。

保存范围包含项目需求/团队待办、项目、列表/看板方式，以及范围、搜索词、状态、优先级、负责人、阻塞条件。页码、打开的需求、需求正文和权限不保存。使用视图会回到第一页。

“管理视图”支持使用、重命名、更新为当前页面条件及删除。更新条件会替换原项目、筛选及显示方式；删除只移除个人偏好，不删除需求。同一用户在同一团队内的名称不可重复；并发修改使用版本检查，冲突时保留输入并刷新。

项目权限撤销后，相应视图不再列出；保存和使用均重新检查权限。视图不会授予项目访问权。归档项目可保存只读视图；个人视图不改变项目数据。

## 通知中心

站内通知按当前团队展示，可选择“全部通知”或“仅看未读”，每页20条。筛选与页码保留在URL，刷新仍回到同一页。排序使用创建时间与ID保证同一时间通知的翻页稳定。

- “选择本页未读通知”仅选择当前页未读项；“选中已读”按所选ID提交。
- “当前团队全部已读”需确认，只处理本人的、当前团队内仍有项目权限的通知；其他账号和团队不受影响。
- 未读视图的末页读完后自动回到最后一个仍有效的页码；无未读项时显示明确空状态。
- 点击通知先标记已读，再打开对应需求；失败保留页面并提示，不静默跳转。
- 批量已读可重复执行，已读时间不会被重复覆盖。选择中混入其他账号、团队或不可访问通知时整批拒绝，不部分更新。

通知列表仍支持旧的单条已读接口。批量已读在事务内重查团队及项目身份，与成员管理使用的锁协调；已读总数与分页读取使用一致的数据库快照。
