# 需求详情正文就地编辑

文件导入入口从原先仅在创建/编辑草稿表单中，增加到需求详情“详细信息”的正文顶部。导入后在正文中预览待修改标题和说明等字段，需点击“保存正文修改”才写入；未导入字段保持原值。

草稿的产品负责人可点击正文标题、目标、背景、范围与需求说明、验收标准直接进入文本编辑，无需先打开完整草稿表单。支持键盘Enter/空格进入、保存与取消；验收标准每行一条。保存复用原需求PATCH、版本冲突及权限校验，失败保留输入。

非产品负责人显示明确只读说明；归档项目只读；已提交需求保留提交历史，并为有权限的项目成员提供“发起内容变更”入口，打开现有变更表单。

验证：正文编辑、取消、文件导入保存、保留未导入字段、390px操作、普通成员只读、已提交内容变更表单，以及既有TXT/DOCX/PDF及AI评审专项通过。类型检查与生产构建通过，日志见artifacts/inline-content-build.log。没有后端或数据库结构变更。本轮尚未部署服务器。
