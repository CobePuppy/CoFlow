# 个人菜单与团队导航（v2.3.1）

- 门户和需求工作区使用同一 AccountMenu 组件：点击头像行向上展开，集中个人资料、个人AI设置、偏好设置与退出登录。头像行使用原生按钮，支持键盘与展开状态，菜单支持 Escape 收起。
- 移除侧栏独立个人设置及退出按钮。团队身份在团队上下文展示，个人菜单以账号姓名与邮箱识别个人身份。
- 侧栏只保留既有团队切换器；“加入或创建团队”移动至团队页操作区，加入、创建或选中团队后进入对应团队页面。
- 成员管理的导航、页面标题和应用入口统一命名为“团队”；学生首页统一命名为“工作台”。内部 section=members 链接继续兼容。
- 需求工作区的“团队”入口跳转至相同的团队页并携带当前 workspace，避免在工作区再维护一套团队操作入口。
- 保留学生青绿、企业蓝色主题。没有后端接口或数据库改动，api 保持 2.3.0。

参考依据为用户提供的头像上拉菜单截图。此次浏览器会话已能读取 Makit 需求详情，未要求重新登录，也未修改参考站数据；首页跳转工具超时，未将其个人菜单视为已核实内容。

验证覆盖两套版本的个人菜单上拉方向、设置页跳转、手机端菜单与退出登录，以及团队创建/加入/角色隔离和门户学生版流程。截图见 artifacts/browser/account-menu-student.png、account-menu-enterprise.png、account-menu-mobile.png；详细验证状态记录于 CHANGELOG.md。本轮未部署。
