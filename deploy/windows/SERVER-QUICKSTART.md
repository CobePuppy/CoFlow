# 汇流 CoFlow：服务器首次启动

部署目录：`C:\Users\hp-pcz\AppData\Local\Programs\CoFlow`。

部署包已包含 Node.js、PostgreSQL、应用依赖及编译后的前后端，不需要 SSH，也无需在服务器上执行 pnpm install。只操作本目录中的专用数据库和文件。

## 第一次

1. 双击部署目录中的 `Install-From-Package.cmd`。脚本校验并解压部署包，再进入初始化。输入管理员邮箱（回车默认 admin@coflow.local），再设置至少8位的网站管理员密码。此密码由你现场设置，不是 Windows 登录密码。
2. 初始化脚本创建独立全新数据库、管理员和空白团队，然后启动网站。窗口需要保持运行。
3. 双击 `deploy\windows\Open-Lan-Port.cmd` 并确认管理员授权，开放内网网站端口。该规则仅作用于本程序、8080端口和本地子网。
4. 在同一内网访问 `http://10.16.7.124:8080`，使用刚才设置的管理员账号登录。

## 以后启动

双击 `deploy\windows\Start-CoFlow.cmd`。请不要再次初始化，不要删除 `.env`、`.data` 或 `storage`。

数据库仅监听服务器本机的55439端口，不对内网开放；网站使用8080端口。端口冲突时初始化会停止，先查看窗口输出，不能直接覆盖其他服务。初始化部分失败时会保留现场，请把报错发给维护人员。

## 成员如何注册

登录页选择「注册」：团队创建者填写账号信息与团队名称，即可创建团队并获得团队码；团队队员填写账号信息和团队码，即可加入团队。密码至少8位。管理员也可在「成员管理」中查看、复制团队码。请仅向需要加入的伙伴分享团队码。

注册完成后使用邮箱和密码登录。队员默认为普通成员，项目访问权限仍由管理员分配。原有的邮箱邀请链接仍可使用。

新数据库没有演示账号和项目。管理员先创建项目，再为成员配置项目访问权限。需求中的实际职责可以自由分配，允许兼任；方案保留两位独立评估人的要求。

## 访问地址和域名

当前为内网部署，直接使用上述 IP 地址即可，不必先购买域名。公网访问需要额外的公网入口、域名和 HTTPS 配置。请勿直接把公网域名解析到该内网 IP。

上传附件保存在 `storage`，数据库在 `.data\postgres`，数据库连接配置在 `.env`。这几个位置需要备份且不得公开分享。前端静态文件位于 `apps\web\dist`，不包含数据库配置。

文件已上传不代表网站已经运行：只有执行初始化、启动并验证健康检查后，才算服务器上线。健康检查地址为 `http://10.16.7.124:8080/api/v1/health`。
